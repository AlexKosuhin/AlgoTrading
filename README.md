## Описание проекта

Этот проект представляет собой комплексную систему анализа и прогнозирования эффективности свечных паттернов на основе машинного обучения.
Цель проекта - классифицировать каждую свечную формацию(например, бычье поглощение) на потенциально прибыльную и потенциально убыточную. Прибыльные формации - торгуем, убыточные - нет.

## Архитектура проекта

### 1. Подготовка данных и детекция паттернов

**Функция `good_dataframe()`:**
- Загрузка и предобработка рыночных данных
- Агрегация в различные таймфреймы
- Создание структурированного временного ряда

**Функция `detection_bullish_engulfing_pattern()`:** 
- Автоматическое обнаружение бычьего паттерна "поглощение"
- Два режима фильтрации для повышения точности

**???Функция корректна, однако в дальнейшей работе появляются сложности в обработке. Необходимо сделать более гибкую версию.**

### 2. Тестирование стратегии и создание обучающей выборки

**Функция `lst_trade_statistics_bul()`:**
- Масштабное тестирование стратегии на различных периодах удержания (N = 1-50 свечей)
- **Каждая комбинация (паттерн + период удержания) = отдельная стратегия**
- Расчет комплексных метрик эффективности:
  - Количество сделок
  - Win Rate
  - Общая прибыль
  - Profit Factor

**???Функция корректна, однако можно расширить количество расчетных параметров стратегии, также после изменения предыдущей функции проверить работают ли они вместе?**
### 3. Формирование целевой переменной

На основе результатов тестирования:
- **Прибыльные паттерны** → целевой класс 1
- **Убыточные паттерны** → целевой класс 0
- Отбор лучших стратегий для обучения модели

### 4. Создание признакового пространства

**Функция `shift_features_2_candle()` и расширенная инженерия признаков:**
- Ценовые характеристики двух свечей паттерна:
  - `open_N`, `close_N`, `high_N`, `low_N`, `volume_N`
  - `open_N-1`, `close_N-1`, `high_N-1`, `low_N-1`, `volume_N-1`
- Производные признаки:
  - Размеры тел свечей
  - Соотношения объемов
  - Волатильность
  - Тенденции перед паттерном
  - Контекстные рыночные показатели
  - и ещё миллион

### 5. Задача классификации

**Цель:** Предсказать будет ли свечной паттерн прибыльным или убыточным

**Методы машинного обучения:**
- Бинарная классификация (прибыльный/убыточный)
- Используемые алгоритмы:
  - Деревья решений и Random Forest
  - Градиентный бустинг (XGBoost, LightGBM)
  - Логистическая регрессия
  - Нейронные сети (глянем)

## Ключевые особенности подхода

### Инновационность:
- **Переход от обнаружения к прогнозированию** эффективности паттернов
- **Учет временного горизонта** - разные периоды удержания как отдельные стратегии
- **Комплексное признаковое пространство** на основе двух свечей

### Практическая ценность:
- Автоматический отбор рабочих стратегий
- Прогнозирование результативности до входа в сделку
- Адаптация к различным рыночным условиям
