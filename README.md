## Описание проекта

Этот проект представляет собой комплексную систему анализа и прогнозирования эффективности свечных паттернов на основе машинного обучения.
Цель проекта - классифицировать каждую свечную формацию(например, бычье поглощение) на потенциально прибыльную и потенциально убыточную. Прибыльные формации - торгуем, убыточные - нет.

## Архитектура проекта

### 1. Подготовка данных и детекция паттернов

- Загрузка и предобработка рыночных данных
- Агрегация в различные таймфреймы
- Создание структурированного временного ряда
- Автоматическое обнаружение свечного паттерна, любого, делаем на примере формации "бычье поглощение"


### 2. Тестирование стратегии и создание обучающей выборки

- Тестирование стратегии на различных периодах удержания (N = 1-50 свечей)
- **Каждая комбинация (паттерн + период удержания) = отдельная стратегия**
- Расчет комплексных метрик эффективности:
  - Количество сделок
  - Win Rate
  - Общая прибыль
  - Profit Factor
- Отбор лучшей стратегии для которой мы применим методы классификации

### 3. Формирование целевой переменной

На основе результатов тестирования:
- **Прибыльные паттерны** → целевой класс 1
- **Убыточные паттерны** → целевой класс 0


### 4. Создание признакового пространства
Создаем признаки на основе:
- Индикаторов
- Дат и времени
- Соотношений различных элементов каждой свечи паттерна
- Соотношений различных элементов между свечами паттерна
- Волатильности
- др.

- Стандартизация и нормализация данных. Сложный момент


### 5. Задача классификации

**Цель:** Предсказать будет ли свечной паттерн прибыльным или убыточным

**Методы машинного обучения:**
- Бинарная классификация (прибыльный/убыточный)
- Используемые алгоритмы:
  - Деревья решений и Random Forest
  - Градиентный бустинг (XGBoost, LightGBM)
  - Логистическая регрессия
  - Нейронные сети (глянем)
